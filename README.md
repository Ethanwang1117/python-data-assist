# Data-assist
针对公司的日报业务进行数据处理的小应用


## 项目介绍

本项目旨在提供简单、高效的工具。  
用户无需安装 Python 环境，即可直接运行 EXE 文件。

## 主要功能

- 功能一：读取实时电价数据
- 功能二：读取实时电量数据
- 功能三：处理数据并输出总结表格

## 下载与安装

1. 进入 GitHub 项目的 Releases 页面。
2. 下载最新版本的压缩包文件。
3. 解压相关资源文件。
4. 阅读使用说明并双击 EXE 运行程序。

## 使用教程

详细使用说明请参考项目中的用户手册。  
首次运行需要批准windows防火墙


## 技术栈

- Python
- Windows
